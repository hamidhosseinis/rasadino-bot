# Rasadino | رصدینو

ربات اطلاع‌رسانی استان گلستان — [@Rasadinobot](https://t.me/Rasadinobot)

این مخزن عمومی صرفاً شامل **کد رصدینو** است؛ هیچ فایل، کلید یا دادهٔ مشتری از پروژه‌های دیگر نباید به آن منتقل شود.

## زیرساخت
- Cloudflare Workers: `hamid-price-report-bot`
- ذخیره‌سازی: KV اختصاصی پروژه (binding: `STATE`)
- منطقه زمانی: `Asia/Tehran`
- Secretهای لازم در Cloudflare (مقدارها در مخزن ثبت نمی‌شوند): `BOT_TOKEN`, `WEBHOOK_SECRET`, `LINK_CODE`

## امکانات
- گزارش قیمت بیت‌کوین (دلار)، نفت خام برنت (دلار/بشکه)، تتر و طلای ۱۸ عیار (تومان)، همراه با درصد رشد تاریخی و اعلان اختیاری شخصی ساعت ۱۰ و ۲۲ ایران
- مقایسه تاریخی: نفت برنت با **قیمت مرجع نفت خام در مارس ۱۹۷۸** (۱۲٫۶۶ دلار/بشکه طبق بانک جهانی، شاخص متفاوت از برنت)، طلا با مبنای تقریبی ابتدای ۱۳۵۷ (حدود ۳۰ تومان/گرم)، و بیت‌کوین در برابر اولین نرخ منتشرشده در **۵ اکتبر ۲۰۰۹**؛ درصدها اسمی‌اند و تتر صرفاً با دلار تاریخی مقایسه می‌شود. قیمت روز دلار آزاد نمایش داده نمی‌شود. روش و منابع در دکمه «📚 منابع» ذکر شده‌اند.
- هواشناسی شش شهر منتخب گلستان (بندرگز، کردکوی، گرگان، آق‌قلا، علی‌آباد کتول و گنبدکاووس) با داده‌های Open-Meteo
- منوی فارسی Inline قابل‌بستن و بازگشت با `/start` و `/menu`؛ عضویت عمومی رایگان و اشتراک اعلان با `/subscribe` و توقف با `/stop`
- دکمه «📚 منابع»: نمایش یکجای مراجع قیمت‌ها و پیش‌بینی هواشناسی؛ گزارش‌های قیمت و هواشناسی بدون لینک منبع تکراری هستند
- 🎧 رصد موزیک: جست‌وجوی نام آهنگ یا خواننده در کاتالوگ‌های iTunes و Audius برای فارسی و انگلیسی (کاتالوگ آمریکا)، همراه با اطلاعات اثر و **لینک رسمی صفحه پخش**؛ بدون ذخیره یا ارسال فایل صوتی. از منوی `/music` یا دستور `/findmusic fa گوگوش` و `/findmusic us Taylor Swift` استفاده کنید. بخش ژانر/نوع پیشنهاد/تعداد هنوز رابط آزمایشی است؛ رتبه‌بندی روزانه و پیشنهاد شخصی فعال نشده‌اند.
- پشتیبان: @hamidhosseinis
- گردآوری خبرهای ۴۸ ساعت اخیر استان گلستان از منابع عمومی، با تیتر، زمان و لینک هر خبر در بخش جزئیات (کیفیت داده به دسترسی منابع وابسته است)

## وضعیت رصد موزیک (۱۸ نوامبر ۲۰۲۶)
- **مرحله ۶ نیز منتشر شد:** منوی زبان ← ژانر ← نوع پیشنهاد ← تعداد، اکنون نتیجه‌های واقعی با پیوند رسمی آهنگ ارائه می‌کند؛ نمونه‌ها شامل «جدیدترین‌های دارای تاریخ معتبر»، «گزینش خودکار ژانری»، «جدول هفتهٔ Audius»، «جدول تمام‌دوران Audius» و «Underground Audius» هستند.
- انتخاب «ترند امروز» فعلاً به‌دلیل نداشتن جدول روزانهٔ قابل‌تأیید غیرفعال است. همچنین جدول‌های «هفتگی/تمام دوران/Underground فارسی» تا یافتن منبع معتبرِ فارسی قابل نمایش نیستند؛ نتیجهٔ ساختگی نشان داده نمی‌شود.
- گزینش هوشمند فعلاً **قاعده‌محور و غیرشخصی** است. کاتالوگ آمریکایی iTunes یا Audius به معنی تأیید ملیت خواننده یا زبان آهنگ نیست.
- نسخهٔ فعال Cloudflare: **v28** (`d64ed7d2-b9c4-4e7e-934a-0fd1a5e2916e`)؛ نسخهٔ پیشین **v27** (`44d280e2-f7d7-440c-9144-ae988c35c738`) برای بازگشت حفظ شده است. مستندات [مرحله ششم](docs/MUSIC_STAGE6.md).
- تست خودکار/محلی موفق بوده؛ **تعامل واقعی مرحله ۶ از داخل تلگرام هنوز به تأیید کاربر نیاز دارد**.

## نمایش خلاصه پیام‌ها (۱۹ نوامبر ۲۰۲۶)
- متن‌های قیمت، هواشناسی، اخبار، رصد موزیک، منو و راهنما فشرده شده‌اند؛ تاریخ نرخ نفت، درصدهای رشد، منبع هر خبر در جزئیات و لینک رسمی آهنگ حذف نشده‌اند.
- PR #15 ادغام شد؛ **۷۸/۷۸ آزمون خودکار** و **۵/۵ آزمون HTTP روی Worker اصلی** موفق‌اند. آزمون HTTP معادل تأیید تعاملی دکمه‌های تلگرام نیست.
- این تغییر منطق Cron، اشتراک کاربران، KV یا Secretهای Worker را دست‌کاری نکرده است.

## تاریخچه انتشار موسیقی (مرحله پنجم)
- قابلیت جست‌وجوی رصد موزیک از طریق PR #13 در شاخه `main` ادغام و روی Worker اصلی منتشر شده است. نسخه Cloudflare: `26337585-268d-423f-9b74-98b8eca07264`.
- **۶۵ تست واحد/یکپارچه** و آزمون محلی Worker قبلاً موفق شده‌اند؛ همچنین **۵ آزمون HTTP واقعی** روی Worker اصلی (سلامت، قیمت، خبر، جلوگیری از Webhook تقلبی، بسته‌بودن مسیر HTTP موسیقی) موفق بود.
- هنوز تأیید نهایی تعامل کاربر حقیقی با منوهای موزیک در محیط تلگرام ثبت نشده است؛ برای آزمایش عملی از `/music` استفاده کنید. اجرای تست HTTP به‌تنهایی معادل آزمون تعاملی نیست.
- مستندات: [مرحله پنجم](docs/MUSIC_STAGE5.md). انتشار GitHub خودکار نیست.

## وضعیت هماهنگ‌سازی کد
نسخه مبنای منتشرشده در Cloudflare و توسعه چندکاربره در فایل `src/worker.mjs` نگهداری می‌شود. انتشار GitHub به Cloudflare **خودکار نیست**؛ برای استقرار باید نسخه و bindings در Cloudflare جداگانه کنترل شوند. روش آزمون و مهاجرت در [docs/PUBLIC_USERS.md](docs/PUBLIC_USERS.md) شرح داده شده است. برای هر تغییر، موفقیت آزمون خودکار و انتشار به‌تنهایی جایگزین بررسی عملی دکمه‌ها در تلگرام نیست.
