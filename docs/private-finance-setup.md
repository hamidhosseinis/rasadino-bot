# رصدینو | حسابداری شخصی (آماده اتصال، نه فعال در تولید)

**حریم خصوصی:** این قابلیت فقط برای Telegram chat ID مالک ثبت‌شده در کلید KV موجود \`owner_chat_id\` است. کاربران عمومی منوی مالی را نمی‌بینند. فایل Google Sheets باید خصوصی باقی بماند و **هیچ رکورد مالی، ID شیت، کلید یا URL Web App در مخزن عمومی ذخیره نشود**.

## پیش‌نیازها

- یک Google Sheet خصوصی با شیت‌های دقیقاً: \`هزینه‌ها\`، \`وام‌ها و بدهی‌ها\`، \`چک‌ها\`، \`دسته‌بندی‌ها\`، \`گزارش ماهانه\`.
- کد اتصال: \`scripts/personal-finance-apps-script.gs\`.
- Cloudflare Worker: \`hamid-price-report-bot\` با اتصال موجود \`STATE\`.

## اتصال دسترسی گوگل (تنها مرحله نیازمند تأیید مالک)

1. در \`script.google.com\` یک پروژه جدید بساز؛ کد فایل \`.gs\` فوق را در آن بگذار.
2. از Project Settings > Script properties دو مقدار زیر را تنظیم کن:
   - \`FINANCE_SHEET_ID\`: شناسه فایل Google Sheet خصوصی
   - \`FINANCE_API_TOKEN\`: توکن تصادفی بسیار قوی، دست‌کم ۳۲ نویسه. **توکن را در گیت‌هاب یا چت عمومی قرار نده**.
3. Deploy > New deployment > Web app: \`Execute as: Me\` و \`Who has access: Anyone\`. مجوز دسترسی به Google Sheets را فقط برای پروژه‌ای که خودت ایجاد کرده‌ای تأیید کن. URL نهایی \`/exec\` را نزد خود نگه دار؛ URL بدون توکن قادر به خواندن/نوشتن داده نیست.
4. در Cloudflare Worker دو secret بساز: \`FINANCE_API_URL\` (آدرس \`/exec\`) و \`FINANCE_API_TOKEN\` (همان توکن مشترک).
5. یک نسخه آزمایشی Worker (جدا از Production) با این branch بساز و قبل از هرگونه انتشار، آزمون‌های خودکار، ثبت یک رکورد تستی و گزارش ماه را تأیید کن.
6. سپس با رضایت مالک و داشتن مسیر برگشت، PR را merge و نسخه را deploy کن. API توکن را در logs چاپ نکن.

> امنیت: Web App در سطح شبکه عمومی است اما درخواست‌ها فقط با توکن محرمانه پذیرفته می‌شوند؛ توکن باید قوی و قابل چرخش باشد. برای افزایش امنیت در آینده، می‌توان یک API با OAuth2 یا یک service account با مجوز محدود به یک شیت جایگزین کرد.

## قالب‌های پیام بات (فقط مالک)

- \`هزینه ۲۵۰ هزار تومان بنزین\`
- \`هزینه | ۲۵۰۰۰۰ | حمل‌ونقل و سوخت | بنزین خودرو | کارت\`
- \`وام | بانک ملت | ۵۰ میلیون | ۳ میلیون | ۱۴۰۵/۰۹/۱۵ | خرید خودرو\`
- \`بدهی | علی | ۵ میلیون | ۱۴۰۵/۰۹/۱۵ | قرض\`
- \`چک | صادره | ۱۴۰۵/۰۹/۱۵ | ۱۰ میلیون | دریافت‌کننده | ۱۲۳۴\`

\`/finance\` یا دکمه «💼 حسابداری من» برای مالک: ثبت، گزارش هزینه‌های ماه، فهرست بدهی‌های فعال و چک‌های در انتظار. همه ارقام بر حسب تومان؛ **مبلغ و تاریخ باید قبل از ارسال درست باشند**.

## یادداشت عملیاتی

- ثبت‌ها در Google Sheet انجام می‌شوند؛ Worker فقط دستورها را پردازش می‌کند. داده‌های مالی نباید در Cloudflare KV ذخیره شوند.
- کلید \`tg:<update_id>\` مانع ثبت تکراری همان پیام تلگرام است.
- گزارش ماهانه براساس ستون «ماه شمسی» است. ستون‌های «مانده» و «وضعیت» در شیت قابل اصلاح دستی‌اند؛ ثبت پرداخت اقساط و اعلان پیش از سررسید هنوز در این نسخه توسعه نیافته‌اند.
- نصب خودکار اسکریپت و اتصال OAuth Google با Google Drive ChatGPT connector انجام نمی‌شود؛ این connector جایگزین اعتبارنامه دائمی Cloudflare نیست.
- بازگردانی: PR را merge نکن یا در Production به نسخه قبلی Worker برگرد. شیت مالی خصوصی به حالت خود باقی می‌ماند.
